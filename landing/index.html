Compiled · Statically typed · No garbage collector

The simplicity of Go.
The expressiveness of C#.
Native code without GC pauses.

Zell is a language for services, tools and command-line programs. Errors are values without the boilerplate, async/await runs on a multi-threaded scheduler, and memory is freed deterministically by reference counting.

Tooling

      
Everything in one archive

      
No clang, no C headers, no SDKs. Unpack it and build for any supported platform.

    

    

      

        
        
One command

        
zell build, run, test, fmt, doc and check.

      

      

        
        
Editors

        
A language server with typed completion, refactorings and type hierarchy. Extensions for VS Code and IntelliJ; works with Neovim and Helix.

      

      

        
        
Packages

        
zell.toml manifests, a lock file and workspaces. Dependencies come straight from Git.

      

      

        
        
Cross-compilation

        
Linux on x86-64 and arm64, glibc or fully static musl, macOS and Windows from any host.

      

      

        
        
Testing

        
Tests and benchmarks next to the code. t.Must unwraps results and reports the file and line.

      

      

        
        
Debugging

        
DWARF for lldb and gdb with pretty-printers. A panic ends its task and prints a backtrace with file and line.
